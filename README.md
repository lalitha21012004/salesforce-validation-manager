# Salesforce Validation Manager - Frontend

A modern React.js web application that connects to Salesforce via OAuth 2.0 and allows users to dynamically view, activate, and deactivate Salesforce validation rules in real time using the Salesforce Tooling API.

---

## 🚀 Live Demo

- **Application URL:** [https://salesforce-validation-manager-rho.vercel.app](https://salesforce-validation-manager-rho.vercel.app)

---

## ✨ Features

- **OAuth 2.0 Salesforce Login:** Securely authenticates with any Salesforce Developer Org without hardcoding credentials.
- **Dynamic Rule Fetching:** Queries and displays validation rules (Name, Status, Actions) across connected org objects.
- **Real-Time Toggle:** Allows users to activate or deactivate validation rules directly within Salesforce with immediate state updates.
- **Responsive UI:** Clean, intuitive interface built with React.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React.js
- **Styling:** CSS3 / Modern Flexbox & Grid
- **Deployment Platform:** Vercel
- **Backend Service:** Node.js / Express API (Hosted on Render)
